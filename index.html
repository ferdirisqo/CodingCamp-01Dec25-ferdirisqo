Portfolio

Project Terbaru

Ini adalah proyek terbaru yang saya kerjakan, proyek ini menjadi ajang bagi saya untuk menerapkan keterampilan terbaru yang saya pelajari.

Web E-commerence

Saya mengembangkan sebuah website e-commerce yang berfungsi untuk menampilkan produk, mengelola keranjang belanja, serta memproses transaksi secara mudah dan terstruktur. Proyek ini mencakup pembuatan tampilan yang responsif, integrasi sistem login, serta pengelolaan data produk dan pengguna. Dengan sistem ini, proses jual beli menjadi lebih praktis dan dapat diakses dari berbagai perangkat.

Membuat PCB

Saya mendesain dan membuat PCB (Printed Circuit Board) untuk kebutuhan rangkaian elektronik pada proyek yang saya kerjakan. Prosesnya meliputi pembuatan skematik, penentuan jalur (routing), pengaturan layout komponen, hingga menghasilkan desain akhir yang siap dicetak.

Membuat database dengan MySQL

Saya menggunakan MySQL untuk membuat dan mengelola database pada berbagai proyek. Prosesnya dimulai dengan membuat database baru menggunakan perintah dasar CREATE DATABASE, kemudian dilanjutkan dengan membuat tabel, menentukan struktur data, serta mengatur relasi antar tabel. Dengan MySQL, saya dapat membangun sistem data yang rapi, efisien, dan mudah dikembangkan

Mengkonfigurasi DHCP pada Switch Cisco

Saya melakukan konfigurasi DHCP pada switch Cisco untuk menyediakan alamat IP secara otomatis kepada perangkat yang terhubung. Proses ini meliputi pembuatan DHCP pool, pengaturan network, default gateway, serta pengecualian alamat tertentu. Dengan konfigurasi yang tepat, jaringan dapat berjalan lebih efisien dan memudahkan manajemen perangkat dalam skala kecil maupun besar.
